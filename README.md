# Daily Task and Challenge

A collection of daily tasks and coding challenges, organized by date, for practice and keeping track of progress.

## Structure

Each day's work goes in its own folder, named by date:

```
Daily task and challenge/
├── README.md
├── 2026-10-29/
│   ├── README.md      # Problem statement, approach, and notes
│   └── solution.*     # Solution code
└── ...
```

## Adding a New Entry

1. Create a folder named after today's date (`YYYY-MM-DD`).
2. Add a `README.md` inside it with:
   - **Task / Challenge:** what had to be done
   - **Approach:** how you solved it
   - **Notes:** anything you learned or would do differently
3. Add your solution files.
4. Add a row to the log below.
